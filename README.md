# 玻璃加工厂 · 三维工艺原理

基于 Three.js 的玻璃加工厂精细化三维模型，用可交互的动画演示平板玻璃、钢化玻璃和玻璃瓶从原料到成品的加工原理。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端里显示的地址（默认 http://localhost:5173）。`npm run build` 生成可部署的静态文件到 `dist/`。

## 厂区内容

| 跨 | 工位 | 演示的原理 |
| --- | --- | --- |
| 中间跨：浮法线 | 1 原料配料 | 5 种原料筒仓 → 称量 → 混合 → 斜皮带 → 投料机；碎玻璃回收皮带从冷端送回 |
| | 2 熔化与澄清 | 蓄热式横火焰窑：左右小炉每 20 s 交替换火，格子砖随之蓄热/放热；剖切可见玻璃液对流环、上浮气泡、漂浮的配合料堆 |
| | 3 锡槽成形 | 玻璃液越过唇砖流到锡液面摊平；7 对拉边机；玻璃带宽度、厚度、温度沿程变化 |
| | 4 退火 | A/B/C/D/F 五个温区，标注各区温度 |
| | 5 冷端切割与堆垛 | 在线检测、斜置横切桥（刀头随玻璃带同步移动划出垂直切痕）、纵切、掰断、掰边落料、翻转台堆垛到 A 字架 |
| 右侧跨：深加工 | 6 磨边与清洗 | 双边磨边机磨轮与冷却水、毛刷清洗 |
| | 7 物理钢化 | 炉内往复摆动加热至约 650°C → 风栅上下对吹急冷；"应力光弹"模式显示钢化风斑 |
| 左侧跨：瓶罐线 | 8 瓶罐成型 | 料道 → 供料机冲头与剪刀 → 分料溜槽 → 4 组 IS 机按吹-吹法错相成型（料滴 → 初型 → 翻转 → 正吹成瓶 → 钳瓶 → 推瓶） |
| | 9 退火与检验 | 退火炉、自动检验、不合格品剔除、装箱码垛 |

所有炽热玻璃的发光颜色由同一条"温度 → 辉光"曲线计算，可以对照左下角的色标读出温度。

## 操作

- 左侧列表或场景里的编号标签：飞到对应工位，右侧面板显示原理、参数和示意图
- 底部控制栏：暂停/播放、0.5–4 倍速、剖切视图、应力光弹、标签、自动导览、昼夜切换
- 快捷键：`0–9` 切换工位，`←/→` 上一步/下一步，`空格` 暂停，`C` 剖切，`S` 应力，`L` 标签，`T` 导览，`N` 昼夜

## 代码结构

```
src/
  main.js              渲染器、相机、后期泛光、主循环
  ui.js                工位导航、讲解面板、控制栏
  core/
    layout.js          全厂坐标与节拍参数
    materials.js       程序化贴图、材质库、温度辉光色
    effects.js         火焰、粒子、应力光弹着色器
    util.js            几何合批、辊道、标签、工人模型等
  factory/             各车间建模与动画（building / batchHouse / furnace / floatLine / coldEnd / temperingLine / bottleLine）
  data/
    stations.js        各工位讲解内容与相机视角
    diagrams.js        讲解面板里的原理示意图（SVG）
```

运动部件的位置都由"演示时间"的纯函数算出，因此调速、暂停时各工位始终同步。为便于观看，时间做了压缩，屏幕上的速度比真实产线快得多。
